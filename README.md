# Ecom React Project

This is a React-based e-commerce front-end project built using **Vite** for fast development, **Tailwind CSS** for styling, and **React Router** for navigation. It also integrates **Axios** for API calls and **React Toastify** for notifications.

---

##  Features

- Fast development with Vite
- Modern UI with Tailwind CSS
- Routing via React Router DOM
- Notifications using React Toastify
- API integration via Axios
- Unique IDs via NanoID
